# Supplied artwork samples

Eight images supplied for this project were processed with the imagegen crop/extraction workflow, removing the photographed exterior wall/shadow (and the existing outer frame in sample08). The white/cream areas inside the paintings remain part of each texture. JPEG encoding preserves the processed dimensions; these are AI-assisted prepared assets, not a claim of pixel-identical geometric cropping of the originals. Original user files were left unchanged.

The current catalogue uses sample-01 through sample-08. Display titles and default centimetre widths are illustrative, not verified artist titles or physical measurements. Heights follow each prepared image's aspect ratio. Enter measured dimensions in the editor for scale.

Each JPEG is below1MiB and2048px on its longest edge, within the current importer limits. manifest.json records exact dimensions/bytes. An import-only copy is available locally under artifacts/import-ready-samples and artifacts/artspace-samples-import.zip.

These images are user-supplied, and do not inherit the previous geometric demo collection's CC0 attribution. No ownership or licensing rights for the depicted original works are asserted by this repository.
