# ArtSpace iPhone Expo Go companion

SDK 58 preview sharing the repository's screens and repositories, with a dedicated AR availability route. Native Viro AR is excluded. See [setup, limitations and verification](../../docs/EXPO_GO_IPHONE.md).

Install root dependencies first, then run `npm ci` and `npm start` in this folder. Keep this package and lockfile isolated from the native SDK 57 app. Firebase configuration belongs in this folder's ignored `.env.local`.
